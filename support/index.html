Getting started with RightOwner

  1. Install RightOwner from the Microsoft Teams app store or Microsoft AppSource.
  2. A Microsoft 365 admin opens it first, approves the app's permissions, and clicks Create the directory. This creates a SharePoint list called “RightOwner Directory” on your company's SharePoint home site.
  3. Add items manually, or import a spreadsheet (CSV) with the columns: Item, Category, Description, Owner email, Backup email. Use More → Download CSV template for an example.
  4. Anyone with access to your SharePoint home site can search RightOwner in Teams. People with Edit access to that site can add entries.
  5. An entry can be changed or deleted only by its owner, its backup or the person who added it. Everyone else can view it and use Chat with owner to ask for a change.
  6. More → Activity history shows every add, edit, delete and import made in RightOwner, who made it and when. Deleted entries can be restored from there. The history is kept in a SharePoint list called “RightOwner Activity Log” on the same site.

Common questions

Who can add, edit or delete entries?

Anyone with Edit access to your company's SharePoint home site can add entries. An entry can be changed or deleted only by its owner, its backup or the person who added it. Everyone else can search and view. Your admin controls Edit access in SharePoint.

What if something is deleted by mistake?

Open More → Activity history. It lists every add, edit and delete with who made it and when, and deleted entries have a Restore button.

What happens when an owner leaves the company?

RightOwner flags items whose owner's account is disabled or removed. Use Hand over their items to move them to someone new in one step.

How do I remove RightOwner and its data?

Uninstall the app from Teams, then delete the RightOwner SharePoint lists (“RightOwner Directory” and “RightOwner Activity Log”). Your admin can remove the app's permissions in Microsoft Entra ID. If you had a paid plan, cancel it in the Microsoft 365 admin center.

Does RightOwner send our data anywhere?

Your directory data stays in your Microsoft 365. For paid plans, the app sends only your organization's Microsoft tenant ID to our billing service to check which plan you have.
